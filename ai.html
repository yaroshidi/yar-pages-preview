How AI fits in

01

The standard is a file

Naming, structure, motion timings, CMS patterns and handover rules live in versioned markdown. Every project starts from them, so output doesn’t drift between clients.

02

Claude Code drives Webflow directly

Through the Webflow MCP, Claude Code makes edits on the real site: porting components, setting up collections and cleaning up classes.

03

Judgement stays with me

Design decisions, site structure and anything you’ll be judged on stay with me. The speed-up is in the build work, which is where the hours used to go.
